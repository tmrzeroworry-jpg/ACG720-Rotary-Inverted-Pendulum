# UI02曲线差异与硬件单位

C3帧格式和UI01一致：24字节、大端，AA C3 01 18，op、保留0、seq16、session32、signed velocity_q16、acc_step16、TTL16、CRC16、CRLF。CRC覆盖前20字节。速度单位为编码器计数/ms乘65536，加速度为每1ms的Q16速度步长。1040 counts/rev，1kHz控制节拍。

换算Q=65536*1040/(360*1000)。速度参考限制±68157（359.9977°/s）；加速度步长1～136，实际最高718.33683894°/s²。新顶层显式覆盖速度流模块的旧默认参数，单独实例化模块的旧测试仍保留原上限。

V8遥测仍为172字节、115200/8N1、50Hz，BUILD_ID由UI01变UI02，原字段偏移不变。高层C4控制帧格式和TTL500ms不变。新上位机运动入口仅接受UI02/V8；历史解码同时保留UI01及原有版本。

停止曲线后，速度流enabled可能继续为1以保持参考位置。高层互斥判断使用enabled且(velocity非0或desired非0)，完全停止后接受的新任务再通过task_cmd取消旧流；从累计参考平滑交接，不清零参考。

未放宽原有S0直接输出门控、整机网页租约、300ms速度流看门狗、摆角保护、2200counts/s编码器失控保护、禁止自动重启等条件。720°/s²是输入请求边界，界面和服务端按量化实际718.34校验曲线斜率，不能把定点量化误差作为额外加速度能力。
