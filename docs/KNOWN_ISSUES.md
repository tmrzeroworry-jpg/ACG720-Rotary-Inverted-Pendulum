# 基线已知限制（本次清理未修复）

以下依据现有代码审计和 2026-11-01 实测，描述的是 UI02 原有行为。

| 项目 | 当前表现 |
|---|---|
| 受控回落准备 | 摆角、横臂速度需连续满足安静条件；编码器量化和配重后的微动可能反复重置计时。2 秒内未满足会以原因码 9 退出，不进入主动回落。最近实测即为此结果。 |
| 回落底部确认 | 对静止条件较严格，可能无法完成确认并超时。 |
| 快速起摆确认 | 已处于 BALANCE 时，一次较大的误差也可能立即按失败路径退出。 |
| 翻转按钮准入 | 网页按钮可用条件和 FPGA 最终准入并不完全一致，板端仍可能拒绝。 |
| 动作握手互斥 | 特殊动作握手尚未进入板端 busy 的短窗口存在竞态，清理版保留原行为。 |
| 低加速度曲线转回落 | 速度流减速允许较长时间，但回落请求等待曲线结束仍使用 4 秒预算，可能提前放弃。 |
| 网页 / 上位机断连 | 存在网页续期、C4 整机 500 ms、C3 动作续期等保护；断连并不保证继续稳摆。实测关闭串口后约 0.49 秒停止，不能宣称“上位机断连不影响稳摆”。 |
| 定位坐标偏差 | 最近实测相对软件目标存在系统偏差；显示 Reset 不能消除实际定位偏差。 |
| ADC 偶发异常 | 历史调试出现过读数冻结或零值，需要按实际接线与记录诊断；不能以删除保护来绕过。 |

本次没有实施此前提出的运动或心跳修正，也没有放宽任何准入、限幅或停止条件。快速起摆、受控回落和更高速的曲线能力仍需分别验证。
