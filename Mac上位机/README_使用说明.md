# UI02 Mac上位机

本版支持网页运动控制，完整用法和限制以根目录README.md为准。双击根目录“启动Mac上位机.command”，默认127.0.0.1:8777。程序仅绑定本机地址。

自绘速度曲线默认16点、15秒；默认限值180°/s与360°/s²，最高360°/s与720°/s²。编辑、精确JSON、导入导出及实时有效修改均保留。新控制需UI02/V8固件，旧固件只可显示/导出，不发送运动操作。

连接并记录→启用网页控制→选择起摆方式并起摆→稳摆后执行定点/恒速/正弦或更多动作。S0始终急停；网页接管时S1～S4忽略。整机“立即停止”与保留稳摆的“减速停止曲线”各有独立用途。受控回落、快速起摆仍保留原试验状态，UI02未修复旧问题。

姿态、角度、连续横臂位移和速度、大字/左侧竖排标题、横臂动态放大、时间窗、冻结、Reset显示归零保持。Reset只改变浏览器显示坐标，不改变控制参考或串口原始数据。

历史实验数据导出：刷新记录→选择文件→分析记录→选择试验或全部→生成→下载ZIP。包含编码器原始累计/取模值、电位器ADC/电压、时间戳和原始串口。CSV使用UTF-8 BOM及Windows换行。新采集保存在本目录recordings；既有UI01记录仍在旧包，可导入或复制后查看，未搬移删除。内置WE20样例仅代表历史记录。

关闭网页、USB断开或服务退出不会自动恢复运动。后台服务可由“停止上位机.command”停止。
