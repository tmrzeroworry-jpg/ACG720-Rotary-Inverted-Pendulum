# 历史实验数据导出（Windows可用）

1. 启动Mac上位机，在“试验记录”区域点击“历史实验数据导出”。不用断开正在采集的串口。
2. 选择以前保存的串口记录，点击“分析记录”。列表包含本目录recordings里的非空.bin以及已导入/内置记录。
3. 选择某一试验，或“全部样本（含待机）”，点击“生成数据包”。同一次记录内重启后的试验编号会按区间分开。
4. 点击“下载ZIP”，把ZIP发给Windows电脑即可。上位机目录exports中也保留一份。Windows不需要运行Mac上位机，解压后直接使用CSV。

数据包：samples.csv逐帧数据；raw_uart.bin为所选有效遥测帧原始字节；metadata.json包含来源、质量、显示标定与SHA256；README_数据说明.txt解释所有列和单位。

CSV采用UTF-8带BOM、CRLF换行，Windows Excel可直接打开，Python pandas.read_csv(..., encoding="utf-8-sig")和MATLAB readtable均可读取。

包括时间戳/帧序号、试验编号/阶段、电位器原始ADC/电压、摆杆显示角/方向角/原控制角、编码器原始累计计数/取模计数、横臂连续角度/取模角度/速度及有效标志。

做视频时按time_s对齐，不要把CSV行号当作视频帧。没有强制重采样、插值、补帧或平滑；缺帧仍体现在时间戳和missing_before中。一个试验编号下可能包含停止后等待时间，制作视频可按state_id筛选（2起摆、3捕获、4稳摆、5刹车、7减速）。角度的左右方向用pole_phase_deg绘制，不要只用0～180°倾斜量。连续横臂运动用arm_angle_total_deg，俯视方位用arm_angle_mod_deg。

从正在写入的记录导出时，分析会冻结当时的文件长度，后续新收到的样本不会混入该次导出；想包含新样本请重新分析。无效传感器角度留空、原始码值保留；设备重启断电间隔未知，不虚构时间。CSV试验时间从首次观测样本起算，不代表一定从实际启动时刻开始录制。

显示标定只影响显示角列，原ADC、累计计数和原控制偏角保留不变。默认WEXF显示上端6251沿用软件参考、下端20039来自静止记录，参数写入metadata；这不等于精密物理角度标定。

18项后端测试与显示测试已通过；另将真实试验5的63,219行CSV与导出原始帧逐一核对，ADC、编码器、帧序号一致，导出帧CRC错误为0。原始记录中的坏帧、缺帧统计如实写入metadata，不伪造丢失样本。

仅更新Mac上位机；原始39个工程文件、运动控制和所有.fs均未修改，无需烧录。
